# CK3 Localization Manager — как запустить и проверить

Приложение находит все моды CK3 из мастерской Steam, показывает полноту
русской локализации, переводит недостающее (через нейросеть-чат бесплатно
или через API) и записывает перевод прямо в мод, не трогая файлы автора.
Всё записанное хранится в базе и восстанавливается после обновлений Steam.

## Установка (один раз)

1. Установите Python 3.12 или новее с [python.org](https://www.python.org/downloads/)
   (при установке отметьте галочку **Add Python to PATH**).
2. Дважды щёлкните **install.bat** и дождитесь «Готово».

## Запуск

Дважды щёлкните **run.bat** — откроется окно приложения.
Нажмите «Сканировать библиотеку»: появится список всех модов со сводкой.

## Проверка тестов

Дважды щёлкните **run_tests.bat** — в конце должно быть
**«ВСЕ ТЕСТЫ ПРОЙДЕНЫ»**.

## Сценарий 1: перевести мод бесплатно через нейросеть-чат

1. В таблице выберите фильтр «Без русского», откройте любой мод двойным кликом.
2. Нажмите **«Экспорт задания для LLM…»** — сохранятся два файла:
   `*.jsonl` (задание) и `*.prompt.txt` (инструкция).
3. Откройте любой чат с нейросетью (Claude, ChatGPT, DeepSeek…),
   вставьте текст из `*.prompt.txt` и прикрепите/вставьте содержимое `*.jsonl`.
4. Сохраните ответ нейросети в файл (тот же формат, расширение `.jsonl`).
5. В приложении нажмите **«Импорт перевода…»** и выберите этот файл.
   Приложение проверит каждую строку и покажет, что принято и что отклонено.
6. Нажмите **«Записать перевод»** → подтвердите. Готово: в папке мода
   появилась папка `localization/russian`, в игре — русский текст.

## Сценарий 2: перевести встроенным переводчиком (API)

1. В главном окне нажмите **«Ключи API…»**, выберите провайдера
   (Google / Yandex / DeepL / Claude / OpenAI-совместимый) и вставьте ключ.
   Ключ хранится в защищённом хранилище Windows.
2. Откройте мод → **«Перевести через API…»**. Сначала показывается смета:
   сколько строк закроется бесплатно (ванильная локализация CK3 и память
   переводов) и сколько пойдёт в API.
3. Нажмите «Перевести», затем — «Записать перевод».

## Сценарий 3: мод обновился

1. Запустите приложение и нажмите «Сканировать библиотеку».
2. В уведомлениях появится: «…обновился, локализация изменилась: +12 ~7 -3».
3. Откройте мод: новые строки — «Не переведено», изменённые — «Устарело»
   (в редакторе видно старый и новый английский текст рядом).
4. Доперевести можно любым способом (сценарий 1 или 2), затем
   «Записать перевод».
5. Если Steam стёр прошлый перевод при обновлении — нажмите
   **«Проверить/восстановить»**: приложение вернёт всё из базы одним кликом.

Имитация обновления для проверки: удалите вручную папку
`localization/russian` из папки переведённого мода
(`steamapps/workshop/content/1158310/<ID>/`), затем в приложении нажмите
«Проверить/восстановить» — файлы вернутся.

## Сценарий 4: перевести всё сразу

Главное окно → **«Перевести все…»** → выбрать провайдера → «Запустить».
Все моды без русского будут переведены и записаны по очереди.

## Командная строка (то же самое без окна)

```
python -m ck3loc scan                     сводка по библиотеке
python -m ck3loc report <ID>              отчёт по моду
python -m ck3loc snapshot                 снимки локализаций (точка отсчёта)
python -m ck3loc changes <ID>             что изменилось у мода
python -m ck3loc export <ID>              файл-задание для LLM
python -m ck3loc import <ID> <файл>       импорт перевода
python -m ck3loc write <ID> [--dry-run]   записать перевод
python -m ck3loc verify <ID> [--restore]  проверить/восстановить
python -m ck3loc key set <провайдер>      сохранить API-ключ
python -m ck3loc translate <ID> [--estimate-only]  перевод через API
python -m ck3loc batch --provider google  перевести все моды без русского
```

## Где что хранится

- **База приложения**: `%LOCALAPPDATA%\ck3loc\` — все переводы, история,
  снимки, память переводов. Резервная копия этой папки = сохранение всего.
- **Резервные копии** перезаписанных файлов: `%LOCALAPPDATA%\ck3loc\backups\`.
- **Файлы автора мода** никогда не изменяются — приложение только добавляет
  свои папки перевода.

## Если что-то пошло не так

- Steam не найден → укажите путь: `python -m ck3loc --steam "D:\Steam" scan`.
- Перевод пропал после обновления мода → «Проверить/восстановить» в карточке.
- Ключ API не работает → проверьте его в «Ключи API…» (удалить и ввести заново).
