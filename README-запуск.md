# CK3 Localization Manager — как запустить и проверить

Приложение находит все моды CK3 из мастерской Steam, показывает полноту
русской локализации, переводит недостающее (через нейросеть-чат бесплатно
или через API) и записывает перевод прямо в мод, не трогая файлы автора.
Всё записанное хранится в базе и восстанавливается после обновлений Steam.

## Установка и запуск

1. Установите Python 3.12 или новее с [python.org](https://www.python.org/downloads/)
   (при установке отметьте галочку **Add Python to PATH**).
2. Дважды щёлкните **run.bat** — при первом запуске он сам доставит
   недостающие библиотеки, дальше просто открывает приложение.
   (Отдельный **install.bat** нужен, только если хотите поставить всё заранее
   или в изолированное окружение.)

При первом запуске приложение спросит **язык программы** (русский, английский,
испанский, французский, немецкий, китайский, корейский) и **язык перевода
модов**. Целевой язык по умолчанию совпадает с языком программы, но его можно
выбрать отдельно — язык интерфейса при этом не изменится. Оба параметра позже
меняются в Настройках.

Дальше приложение само сканирует библиотеку Steam и показывает сводку.

## Моды-русификаторы

Если перевод мода живёт отдельным модом («… — Русификация»), приложение
находит это само: сверяет ключи, читает зависимости мода и помечает
оригинал как «переведён другим модом». Такие строки не считаются
недостающими — переводить нужно только то, чего не хватает и русификатору.

Если кандидатов несколько (бывает у сборников переводов), в карточке мода
можно выбрать нужный или отключить учёт чужого перевода. Пороги определения
настраиваются в Настройках.

## Как устроено окно

- Слева — разделы: **Библиотека**, **Глоссарий**, **Настройки**.
- Вверху «Библиотеки» — плитки со сводкой; клик по плитке фильтрует список
  (например, «Без перевода»).
- Двойной клик по моду открывает его карточку с вкладками:
  **Обзор** (действия), **Строки** (таблица + редактор), **Изменения**
  (что менял автор между версиями), **Диагностика** (проблемы в файлах мода).
- Внизу — строка состояния и кнопка **Уведомления** с историей событий.

## Проверка тестов

Дважды щёлкните **run_tests.bat** — в конце должно быть
**«ВСЕ ТЕСТЫ ПРОЙДЕНЫ»**.

## Сценарий 1: перевести мод бесплатно через нейросеть-чат

1. Нажмите плитку «Без перевода», откройте любой мод двойным кликом.
2. На вкладке «Обзор» нажмите **«Выгрузить задание для нейросети…»**.
   Приложение спросит, что выгружать, и покажет числа: только недостающие
   (обычный выбор), недостающие и устаревшие, или всё вместе с авторским
   переводом. Сохранятся два файла: `*.jsonl` (задание) и `*.prompt.txt`
   (инструкция).
3. Откройте любой чат с нейросетью (Claude, ChatGPT, DeepSeek…),
   вставьте текст из `*.prompt.txt` и прикрепите/вставьте содержимое `*.jsonl`.
4. Сохраните ответ нейросети в файл (тот же формат, расширение `.jsonl`).
5. В приложении нажмите **«Загрузить перевод из файла…»** и выберите его.
   Приложение проверит каждую строку и покажет в журнале, что принято,
   а что отклонено и почему. Если нейросеть вернула не всё (обрезала ответ),
   принимается то, что есть — остальное остаётся в работе, можно догрузить
   следующим файлом.
6. Нажмите **«Записать перевод в игру»** → подтвердите. Готово: в папке мода
   появилась папка `localization/russian`, в игре — русский текст.

Строки можно править и вручную: вкладка «Строки» → выбрать строку →
внизу трёхколоночный редактор (источник при переводе · источник сейчас ·
ваш перевод). Приложение сразу подсказывает, целы ли игровые коды.
Ctrl+Enter — сохранить и перейти к следующей строке.

## Сценарий 2: перевести встроенным переводчиком (API)

1. **Настройки → Ключи API переводчиков**: выберите провайдера
   (Google / Yandex / DeepL / Claude / OpenAI-совместимый), вставьте ключ
   и нажмите «Сохранить». Ключ хранится в защищённом хранилище Windows.
2. Откройте мод → **«Перевести через API…»**. Сначала показывается смета:
   сколько строк закроется бесплатно (ванильная локализация CK3 и память
   переводов) и сколько уйдёт в API.
3. Нажмите «Перевести», затем — «Записать перевод в игру».

## Сценарий 3: мод обновился

1. Запустите приложение (оно сканирует библиотеку само).
2. В уведомлениях появится: «…обновился, локализация изменилась:
   english: +12 ~7 −3».
3. Откройте мод: новые строки получат статус «Не переведено», изменённые —
   «Устарело». В редакторе видно старый и новый исходный текст рядом.
   Вкладка «Изменения» показывает историю: что именно правил автор.
4. Доперевести можно любым способом (сценарий 1 или 2), затем
   «Записать перевод в игру».
5. Если Steam стёр прошлый перевод при обновлении — нажмите
   **«Проверить и восстановить»**: приложение вернёт всё из базы одним кликом.

Имитация обновления для проверки: удалите вручную папку
`localization/russian` из папки переведённого мода
(`steamapps/workshop/content/1158310/<ID>/`), затем в приложении нажмите
«Проверить/восстановить» — файлы вернутся.

## Сценарий 4: перевести всё сразу

Библиотека → **«Перевести всё без перевода…»** → выбрать переводчика →
«Запустить». Все моды без перевода будут обработаны и записаны по очереди;
процесс можно остановить в любой момент, сделанное сохранится.

## Глоссарий

Раздел **Глоссарий** — словарь обязательных соответствий (Realm → Держава).
Термины передаются переводчику и попадают в инструкцию для нейросети.
Стартовый словарь CK3 (66 терминов) загружается кнопкой; свои термины
добавляются сверху, ячейки редактируются прямо в таблице.

## Командная строка (то же самое без окна)

```
python -m ck3loc scan                     сводка по библиотеке
python -m ck3loc report <ID>              отчёт по моду
python -m ck3loc snapshot                 снимки локализаций (точка отсчёта)
python -m ck3loc changes <ID>             что изменилось у мода
python -m ck3loc export <ID>              файл-задание для LLM
python -m ck3loc import <ID> <файл>       импорт перевода
python -m ck3loc write <ID> [--dry-run]   записать перевод
python -m ck3loc verify <ID> [--restore]  проверить/восстановить
python -m ck3loc key set <провайдер>      сохранить API-ключ
python -m ck3loc translate <ID> [--estimate-only]  перевод через API
python -m ck3loc batch --provider google  перевести все моды без русского
```

## Где что хранится

- **База приложения**: `%LOCALAPPDATA%\ck3loc\` — все переводы, история,
  снимки, память переводов. Резервная копия этой папки = сохранение всего.
- **Резервные копии** перезаписанных файлов: `%LOCALAPPDATA%\ck3loc\backups\`.
- **Файлы автора мода** никогда не изменяются — приложение только добавляет
  свои папки перевода.

## Если что-то пошло не так

- Steam не найден → укажите путь: `python -m ck3loc --steam "D:\Steam" scan`.
- Перевод пропал после обновления мода → «Проверить/восстановить» в карточке.
- Ключ API не работает → проверьте его в «Ключи API…» (удалить и ввести заново).
