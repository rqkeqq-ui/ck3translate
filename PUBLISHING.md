# Первый релиз: руководство для автора

У проекта две части: приложение на GitHub и необязательная база данных для него. В Workshop и Paradox Mods загружается только папка `workshop/ck3loc_community_database`, а не исходники приложения и не exe.

## 1. GitHub: что уже подготовлено

- Главная страница: README.md; английская: docs/README.en.md.
- MIT: LICENSE. Сторонние лицензии: THIRD_PARTY_NOTICES.md.
- Галерея: docs/images; подписи и порядок: docs/GALLERY.md.
- Сборки: Actions → Build releases. Ручной запуск сохраняет архивы в Artifacts; тег `v0.1.0` запускает сборку и создаёт черновик Release после успеха всех трёх платформ.
- Текст релиза: docs/RELEASE_NOTES.md.

Для следующей версии обновите `ck3loc/__init__.py` и release notes, сохраните изменения коммитом и создайте совпадающий тег. Не перемещайте уже выпущенные теги.

```sh
git tag -a v0.1.1 -m "CK3 Localization Manager 0.1.1"
git push origin v0.1.1
```

Откройте Actions и дождитесь зелёных сборок. В Releases откройте Draft, проверьте архивы и нажмите Publish release. Не выдавайте исходный код Source code.zip за готовую программу.

Windows: распаковать весь zip, запустить exe. Linux: распаковать tar.gz, запустить файл CK3LocalizationManager. macOS: распаковать zip с .app; текущая сборка для Apple Silicon. Указанные ОС собираются на собственных runners — PyInstaller не является кросс-компилятором.

Перед публичным выпуском полезна проверка на чистой системе: запуск, выбор языка, сканирование тестовой библиотеки, экспорт/импорт, запись в тестовый мод и восстановление. Не проверяйте запись на единственной копии своих модов. Linux/macOS пока помечены предварительными.

## 2. Steam Workshop: первая загрузка

1. Запустите CK3 из Steam до Paradox Launcher. Найдите «Все установленные моды» → инструменты модов → создание мода. Названия пунктов зависят от версии Launcher.
2. Название: `CK3 Localization Manager — Community Database`. Каталог: `ck3loc_community_database`. Версия: `1.0.0`. Выберите доступный подходящий тег.
3. Найдите созданную папку мода. На Windows обычно это `Документы/Paradox Interactive/Crusader Kings III/mod/ck3loc_community_database`. При перенаправлении Документов в OneDrive путь будет другим.
4. Скопируйте содержимое `workshop/ck3loc_community_database` в эту папку. Сохраните внешний `.mod`-файл, который создал Launcher. Не копируйте туда папку всего проекта.
5. Добавьте свою обложку в `thumbnail.png`. Используйте квадратное изображение и проверьте ограничения загрузчика. Галерея программы лежит в docs/images; она загружается отдельно на страницу предмета.
6. Проверьте каталог: `python tools/validate_community_db.py "ПУТЬ_К_ПАПКЕ_БАЗЫ"`.
7. В инструментах модов выберите загрузку в Steam Workshop. Если выбор видимости есть, для первой загрузки выберите Private. Иначе сразу проверьте и измените видимость на странице предмета. Примите соглашение Workshop своим аккаунтом, если будет предложено.
8. Откройте страницу предмета. Число после `?id=` — настоящий Workshop ID. Не придумывайте его заранее.
9. Вставьте готовый RU/EN текст из `workshop/WORKSHOP_DESCRIPTION.txt`. Добавьте изображения по `docs/GALLERY.md`. Во всех первых строках оставьте предупреждение «Не включать в playset».

## 3. Как добавить ссылку в программу после загрузки базы

В `ck3loc/community_db_config.json` замените пустой `workshop_id` на полученное число строкой. Аналогично заполните `workshop_id` в `workshop/ck3loc_community_database/ck3loc-database.json`. `repository_url` уже заполнен.

В descriptor.mod сохраняйте `remote_file_id`, назначенный Launcher. Не заменяйте его случайным ID и не создавайте второй предмет при обновлении. Повторно проверьте базу и загрузите обновление того же предмета.

Соберите новую версию приложения. Кнопка «Новости на GitHub» автоматически станет «Открыть в Workshop». Старые сборки не получают новый встроенный ID сами, но находят установленную базу по marker-файлу при сканировании Steam.

Подпишитесь на предмет, дождитесь загрузки и проверьте Настройки → Community Database: должны появиться версия и число терминов. Сам предмет не должен попадать в список переводимых модов. В playset его не включайте. После появления рабочего GitHub Release можно сделать предмет публичным.

## 4. Paradox Plaza / Paradox Mods

Каталог модов находится на https://mods.paradoxplaza.com/ . Форум Paradox Plaza — отдельная площадка для темы о программе.

Для каталога войдите в аккаунт Paradox, выберите Crusader Kings III и создание/загрузку мода, либо площадку Paradox Mods в загрузчике Launcher, если она доступна. Используйте тот же каталог JSON-базы; при загрузке zip descriptor.mod и ck3loc-database.json должны находиться в корне архива, без лишнего внешнего каталога. Заполните название, описание из docs/PARADOX_DESCRIPTION.txt, обложку и галерею, затем проверьте предпросмотр и опубликуйте. Доступные поля, теги и ограничения показывает текущая форма площадки.

**Ограничение текущей версии:** приложение обнаруживает Community Database через Steam Workshop. Подписка в Paradox Mods сама по себе не подключает базу к приложению. Описание для Plaza прямо сообщает это; не обещайте одинаковую интеграцию. До её реализации можно ограничиться темой-презентацией на форуме со ссылкой на GitHub.

На форуме найдите раздел CK3 для пользовательских модификаций, ознакомьтесь с правилами раздела и создайте тему о внешнем инструменте. Возьмите описание возможностей из README, добавьте скриншоты и ссылку на Releases. Не загружайте exe в тему вместо GitHub Release.

## 5. Обновление базы

Редактируйте JSON в workshop/ck3loc_community_database, увеличивайте database_version и запускайте валидатор. Начальное содержимое: 12 терминов, 0 связей, 0 правил. Не называйте пустой реестр готовой проверенной коллекцией.

В предложениях сообщества проверяйте оба мода, язык, пересечение localization-ключей и актуальность перевода. Не распространяйте чужие игровые файлы. Загружайте обновление существующего предмета и заполняйте Change Notes.

## 6. Что осталось личным

Задания агентам и рабочая спецификация исключены из текущего дерева Git, но сохранены локально. История не переписана: старые коммиты могут содержать эти документы. В этой подготовке не требуется удалять историю ради обычных рабочих файлов. Если когда-либо найдётся настоящий секрет, сначала отзовите его, затем отдельно очистите историю.
