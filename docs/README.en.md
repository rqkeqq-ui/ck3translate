# CK3 Localization Manager
### More stories in your language.

Translate Crusader Kings III mods, track changed text and restore your work after updates.

[Download](https://github.com/rqkeqq-ui/ck3translate/releases) · [Report an issue](https://github.com/rqkeqq-ui/ck3translate/issues) · [Русский](../README.md)

![Mod library](images/01-library.png)

Find missing translations across your installed Steam Workshop library. Export a JSONL translation task with a ready-to-use prompt for a web chat, or connect Google, DeepL, Yandex, Claude and OpenAI-compatible APIs. Web-chat export needs no API key; service availability, pricing and limits depend on the provider. XLIFF exchange is also supported.

Review original text and translations side by side. Keep terms consistent with a glossary and translation memory, use references extracted from your installed CK3, and check game tokens before writing. Coverage measures matching keys, not translation quality.

The app writes its own localization files without overwriting the author's files. Write into the mod directory or create a separate patch mod. Local history and backups help restore app-generated translations after Steam updates; changed source lines can be translated separately.

## Get started

1. Download the archive for your OS from Releases and extract the entire archive.
2. Run the Windows `.exe`, Linux executable, or macOS `.app`. No Python installation required.
3. Choose your languages and scan your library. Set the Steam folder in Settings if necessary.
4. Open a mod, translate missing text, review and write your translation.

Available builds: Windows x64, Linux x64 and macOS Apple Silicon. Check each release for tested platforms and known limitations.

## Community Database

An optional companion dataset for translation-mod links, shared terminology and processing rules. The initial dataset has 12 glossary terms; translation links and mod rules are currently empty. The Steam Workshop page is coming later. The app works without it.

**Do not enable the database in a playset.** Subscribing downloads data, not the desktop application.
